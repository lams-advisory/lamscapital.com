Cumpărare prin AWS Marketplace

Cumpărați serviciile noastre prin contul AWS al firmei.

Pe lângă contractul direct, orice pachet LAMS se poate cumpăra ca ofertă privată pe AWS Marketplace, catalogul de software și servicii al Amazon Web Services. Amazon Web Services facturează firma dumneavoastră și ne plătește pe noi.

De ce aleg firmele această variantă

Oferta privată este o ofertă pe AWS Marketplace făcută doar pentru firma dumneavoastră, în condițiile convenite.

Un furnizor cunoscut

Factura vine de la Amazon Web Services, un furnizor pe care contabilitatea și achizițiile îl pot verifica ușor.

Plata într-un singur loc

Plata trece prin contul AWS al firmei, cu card sau prin transfer bancar, unde este disponibil, iar facturile stau într-un singur loc.

Documente complete

Lunar primiți raportul de activitate, fișa de ore și procesul-verbal de predare, cu numărul ofertei și al facturii AWS, utile la controlul fiscal.

Pașii

1. Stabilim lucrareaSemnăm acordul de confidențialitate și stabilim descrierea lucrării: perimetru, livrabile, calendar și condiții.
2. Deschidem contulDacă firma nu are cont AWS, îl creăm împreună într-o ședință online de 30–45 de minute, pe numele firmei și cu autentificare în doi pași.
3. Acceptați ofertaVă trimitem oferta privată. O acceptați din contul AWS; descrierea lucrării este atașată ofertei.
4. LivrareLivrăm în etape. Lunar primiți raportul, fișa de ore și procesul-verbal de semnat.

Stadiu. Listarea noastră pe AWS Marketplace este în pregătire. Până la publicare lucrăm prin contract direct, în aceleași condiții.

Amazon Web Services, AWS și AWS Marketplace sunt mărci ale Amazon.com, Inc. sau ale afiliaților săi. LAMS este vânzător independent și nu este susținut de Amazon.
